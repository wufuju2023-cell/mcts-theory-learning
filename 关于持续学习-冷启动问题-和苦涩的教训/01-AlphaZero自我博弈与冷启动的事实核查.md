# 第 01 章 AlphaZero 自我博弈与冷启动：事实核查与机制

> 本章结论：（1）AlphaGo Zero（AGZ）与 AlphaZero（AZ）的主结果都是在目标棋盘上（围棋 19×19）从随机权重、仅凭规则直接训练的：主论文没有"先 4×4/9×9 再 19×19"的棋盘尺寸课程；真实存在的是 MiniZero（Gumbel Zero）的模拟预算课程（progressive simulation）与社区复现里的跨棋盘迁移。（2）冷启动之所以可行，由四个结构性条件支撑，其数学内容可归结为三组断言：终局标签处处可得且无偏（命题 1.1）；弱先验下搜索仍保持探索地板与（非退化先验下的）全支撑（命题 1.4）；搜索改进算子在估计世界内恒正、在真实世界内需"估计优势大于两倍模型误差"（命题 1.8）。（3）冷启动的困难是速度而非可行性：自博弈回归信号总存在（命题 1.13），但早期信噪比低、需要规模（AGZ 用 490 万局、70 万 mini-batch）。（4）与证明搜索最关键的结构差别不是"有没有 decoder"这一句话，而是动作空间是否可枚举与标签密度：棋盘搜索里最优根动作从第一次模拟起就在树中，证明搜索里它可能从未被采样（对比 mstc-rl 01 命题 4.4、4.25）。

## 1.0 记号、定位与阅读约定

本章是第 02–06 章的事实与机制基础。记号沿用共享简报 `BRIEF_shared.md` §5：

- 冷启动：$\theta_0$ 为随机初始化；$p_0(B)$ 为"用 $\theta_0$ 的搜索在预算 $B$ 内达到某成功判据"的概率（棋盘的"成功"取"根访问分布把既定质量放到最优动作上"）。

## 1.1 事实核查表

### 1.1.1 AlphaGo Zero（Silver et al., Nature 550:354–359, 2017）

按"从零"这一主张的每个子命题逐条核对：

- **随机初始化、无人类数据、无手工特征**：网络初始化为随机权重，训练从随机行为开始，论文摘要与结论明确写 "learns, tabula rasa"、"without human data, guidance, or domain knowledge beyond game rules"（AGZ 论文摘要与结论；数据集 `top/02`、`math/02` §2.5）。
- **仅游戏规则**：论文在方法节 "Domain Knowledge" 中逐条列出用到的全部先验（规则模拟、Tromp–Taylor 计分、$19 \times 19$ 图像结构、旋转/反射对称），并明确除此之外不使用任何领域知识（AGZ 论文方法节）。
- **不排除任何合法着法**：包括"填自己的眼"这类所有旧程序都会剪掉的点，AGZ 也不排除（AGZ 论文方法节 "Domain Knowledge" 第 1 条末）。
- **MCTS 无 rollout**：叶节点只由 $v_\theta$ 评估，不做蒙特卡洛 rollout（AGZ 论文 §1 与方法节；数据集 `math/02` §2.1）。
- **单一双头网络**：$(p, v) = f_\theta(s)$，残差塔 + 策略头/价值头；价值头 tanh 输出于 $[-1,1]$（AGZ 论文方法节 "Neural Network Architecture"）。
- **数据形式 $(s, \pi, z)$**：$\pi_t = \alpha_{\theta_{i-1}}(s_t)$ 是搜索访问分布，$z_t$ 是终局胜负（从当前行动者视角）；围棋无和棋（7.5 目贴目），故 $z_t \in \{-1, +1\}$（AGZ 论文 §1；数据集 `math/02` §2.3、§2.7）。
- **π 来自温度调节的访问计数**：$\pi_a \propto N(s_0,a)^{1/\tau}$；前 30 手 $\tau = 1$（按访问计数比例采样落子），之后 $\tau \to 0$（贪心取访问最多者）（AGZ 论文方法节 "Self-Play"；数据集 `math/02` §2.2、§2.4）。
- **根 Dirichlet 噪声**：$P(s_0,a) = (1-\varepsilon)p_a + \varepsilon\eta_a$，$\eta \sim \mathrm{Dir}(0.03)$，$\varepsilon = 0.25$（AGZ 论文方法节 "Self-Play"；数据集 `math/02` §2.4）。
- **认输机制**：搜索根值与最佳子值低于阈值 $v_{\mathrm{resign}}$ 时认输；阈值自动选取，使"本可获胜却认输"的假阳性率 $< 5\%$；为测量该率，10% 的自博弈对局禁用认输打到底（AGZ 论文方法节 "Self-Play"）。
- **评估器门控（Evaluator）**：每 1000 步出一个检查点；与当前最优网络对局 400 局、每手 1600 次模拟、$\tau \to 0$，胜率 $> 55\%$ 才让新检查点接管数据生成（AGZ 论文方法节 "Evaluator"；数据集 `math/02` §2.4）。
- **训练规模与超参**：每轮 25,000 局自博弈、每手 1,600 次模拟（约 0.4 秒/手）；回放最近 500,000 局均匀采样；mini-batch 2048（64 个 GPU worker × 32）；SGD + momentum 0.9；L2 系数 $c = 10^{-4}$；MSE 与交叉熵等权；小规模 run 为 20 残差块、3 天、490 万局、700k mini-batch，大规模 run 为 40 残差块、40 天、2900 万局、3.1M mini-batch（AGZ 论文 §2、§4 与方法节 "Optimisation"；数据集 `math/02` §2.4、§2.9）。
- **学习率阶梯**：论文 Extended Data Table 3 给出具体数值（强化学习：0–400k 步 $10^{-2}$，400–600k 步 $10^{-3}$，600k 步之后 $10^{-4}$；监督学习另有阶梯到 $10^{-5}$）。数据集 `math/02` §2.9 曾把该表标为"(S) 图片不可提取"；按本地论文 Markdown 的表格可读版本，此处把具体数值视为已核实（见 §1.8 的存疑记录）。
- **对称增广**：围棋规则在旋转/反射下不变，每个局面生成 8 个对称副本；MCTS 叶评估时随机取一个对称变换（AGZ 论文方法节 "Domain Knowledge" 第 4 条、搜索节 "Expand and evaluate"；数据集 `math/02` §2.9）。
- **战绩与对照**：3 天（20 块）对 AlphaGo Lee 100:0；40 天（40 块）对 AlphaGo Master 89:11；最终 Elo：纯网络 3055、AGZ 5185、AG Master 4858、AG Lee 3739；监督学习基线（KGS 人类棋谱）着法预测准确率 60.4%、优于自博弈网络的预测准确率，但自博弈玩家在 24 小时内就击败了人类监督玩家（AGZ 论文 §2–§4 与 Extended Data Table 1；数据集 `math/02` §2.7）。
- **搜索带来的增益**：纯策略网络（无前瞻）Elo 3055，而带 MCTS 的 AGZ 达 5185，说明搜索作为策略改进算子贡献了约 2000 Elo（AGZ 论文 §4；数据集 `math/02` §2.7）。这是"搜索即教师"命题的直接经验支持。

### 1.1.2 AlphaZero（Silver et al., Science 362:1140–1144, 2018；arXiv:1712.01815）

- **同一算法泛化到围棋/国际象棋/将棋**，每个棋类从零训练一个独立实例（"separate instance"）；论文写明 "Starting from random play, and given no domain knowledge except the game rules"（AZ 论文摘要与方法节 "Configuration"；数据集 `top/03`、`math/03` §3.1）。
- **不再有评估器**：与 AGZ 不同，AZ 维护一个持续更新的网络，用最新参数生成自博弈数据，省略评估与"最优网络"选择步骤（AZ 论文正文；数据集 `math/03` §3.3）。
- **超参跨棋类统一，仅根噪声强度按棋类缩放**：$\alpha_D = \{0.3, 0.15, 0.03\}$ 对应国际象棋/将棋/围棋（按典型合法着法数反向缩放）；除噪声外三个棋类共用全部超参（AZ 论文方法节 "Configuration"；数据集 `math/03` §3.1）。
- **动作编码与掩码**：以规则生成的空间平面或扁平向量表示策略（国际象棋 $8 \times 8 \times 73$，将棋 $9 \times 9 \times 139$，围棋 362 个扁平动作）；非法着法概率置零后重新归一化（AZ 论文方法节 "Representation"；数据集 `math/03` §3.10）。
- **对称性使用差异**：围棋数据用 8 重对称增广、MCTS 叶评估随机对称变换；国际象棋与将棋非对称，不做增广、不做变换（AZ 论文正文；数据集 `math/03` §3.2）。
- **和棋与价值目标**：国际象棋/将棋 $z \in \{-1, 0, +1\}$；价值用平方误差、策略用交叉熵，损失与 (Z1) 相同（AZ 论文正文式 (1)；数据集 `math/03` §3.2）。
- **训练规模**：700,000 步、mini-batch 4096、随机初始化、5000 个一代 TPU 生成对局 + 64 个二代 TPU 训练；学习率 $0.2$ 三次下调至 $0.02/0.002/0.0002$；每步 800 次模拟；国际象棋 9 小时/4400 万局（40 ms/手），将棋 12 小时/2400 万局（80 ms/手），围棋 34 小时/2100 万局（200 ms/手）（AZ 论文方法节 "Configuration"、Table S3；数据集 `math/03` §3.4）。
- **里程碑**：国际象棋 4 小时（30 万步）超过 Stockfish；将棋不到 2 小时（11 万步）超过 Elmo；围棋 8 小时（16.5 万步）超过 AlphaGo Lee（AZ 论文正文；数据集 `math/03` §3.4）。
- **最终对局比分**：对 Stockfish 8 为 28 胜 72 和 0 负；对 Elmo 为 90 胜 2 和 8 负；对 3 天版 AGZ 为 60:40（AZ 论文 Table 1；数据集 `math/03` §3.5）。

### 1.1.3 两个易混的边界

- **"无人类数据"不等于"无任何数据"**：AZ/AGZ 用近 1 亿人类未曾下过的自生成局面；"no human data" 指训练信号不来自人类棋谱与人类评估，而不是"不使用数据"或"不使用先验"（对称性、历史平面、棋盘结构都是先验）。这一区分是第 02 章 Q1 的事实基础。
- **"从零"不等于"一次前向"**：AGZ 的纯网络 Elo 3055 与搜索版 5185 之间的差距说明：网络本身不是零知识达到超人，**搜索回路**才是主力；因此"冷启动"必须理解为"搜索回路从随机网络起能否启动"，而不是"网络从随机权重能否直接下棋"（AGZ 论文 §4）。

## 1.2 "4×4 之问"：AGZ/AZ 有没有小棋盘课程？

### 1.2.1 直接结论（本章最重的更正）

**主结果没有小棋盘课程。** 证据链：

1. AGZ 的输入从头就是 $19 \times 19 \times 17$ 的图像堆叠，输出是 $19^2 + 1 = 362$ 个落子/停着（AGZ 论文方法节 "Neural Network Architecture"）；对局终止条件之一就是 $19 \cdot 19 \cdot 2 = 722$ 手（AGZ 论文方法节 "Domain Knowledge" 第 1 条）。如果存在"先小棋盘后大棋盘"的课程，输入/输出形状与终止规则都必须中途更换，而论文方法节没有任何这样的流程描述。
2. AGZ 的两个主 run（20 块/3 天、40 块/40 天）都从随机行为开始、"完全无人干预"地直接在 19×19 上训练（AGZ 论文 §2、§4）。方法节的训练管线（Optimisation / Evaluator / Self-Play）没有任何按棋盘尺寸分阶段的成分。
3. AZ 的扩展实验同样在每个棋类的完整棋盘上从零训练（国际象棋 8×8、将棋 9×9、围棋 19×19），且强调"不做按游戏调参"（AZ 论文方法节 "Configuration"）。将棋与围棋尺寸不同是**棋类不同**，不是课程。
4. 训练中确实存在"能力按顺序涌现"的现象：AGZ 论文 §3 记录 joseki、life-and-death、ko 等知识先后出现，且 ladder（shicho）反而学得较晚（AGZ 论文 §3）。但这是**涌现顺序**，不是设计的课程：论文没有用前一个能力去构造后一个能力的训练分布。

因此，凡出现"AlphaZero 先在 4×4（或 9×9）上训练再迁移到 19×19"的表述，都与主论文冲突。

### 1.2.2 误记的可能来源

按 BRIEF_shared §3 的核对结论与本地材料，可归为四类：

- **MiniZero 的实验设置**（最可能）：MiniZero 用 9×9 围棋、8×8 Othello、57 个 Atari 游戏做算法对比，并引入 progressive simulation（模拟预算 2 增长到 200）（MiniZero 论文摘要、§III-C、§IV）；这些是**实验平台尺寸**与**预算课程**，不是 AGZ/AZ 的训练方法。把"MiniZero 在 9×9 上训练"读成"AlphaZero 先在 9×9 上训练"是典型串台。
- **社区复现的跨棋盘迁移**：部分复现/后续工作用较小棋盘预训练再迁移（该类工作的具体清单与课程细节未在本地材料逐条核对，(S)）；这属于工程经验，不改变主论文事实。
- **AlphaGo(2016) 的人类数据阶段**：AlphaGo Fan/Lee 先用人类棋谱做监督学习、再自我博弈强化（AGZ 论文方法节 "AlphaGo versions"）；"先在小规模人类数据上热身"的印象可能来自这一段历史，而非 AGZ。
- **教学/单元测试的小棋盘**：4×4、6×6 棋盘常被用于快速验证 MCTS/自我博弈实现（如 Othello/四子棋的玩具版本），这类复现实验与"AGZ 用了课程"是两回事（此类项目未在本地材料收录，(S)）。

### 1.2.3 必须区分的两种"课程"

- **棋盘尺寸课程**（board-size curriculum）：先在 $4 \times 4$/$9 \times 9$ 上训练再扩到 $19 \times 19$。AGZ/AZ 主结果**没有**。
- **模拟预算课程**（simulation-budget curriculum）：棋盘尺寸不变，训练早期用很少的 MCTS 模拟、后期逐步增大。MiniZero 的 progressive simulation 是真实存在的这一类，且仅用于其 Gumbel Zero 训练（MiniZero 论文 §III-C、§IV-F）。AGZ/AZ 的主结果也**没有**用这一类：AGZ 全程 1600 sims/手，AZ 全程 800 sims/手（AGZ 论文方法节；AZ 论文 Table S3）。

相应地，"冷启动课程"在第 03 章的形式化里应当指第二种（预算/分布调度），而不是第一种（状态空间扩张）。本章 §1.5 给出预算课程的简化模型。

## 1.3 自我博弈为什么能学习：四个结构性条件与三组数学断言

### 1.3.1 四个条件（本章对 Q2 的核心回答）

冷启动能启动，依赖以下四条**同时**成立的结构条件；它们是把棋盘博弈与"裸证明搜索"分开的真正分界线：

1. **合法动作有限、可枚举、且全部可用**：$\mathcal A(s)$ 是有限集，搜索可以（原则上）在根节点一次枚举全部合法着法；AGZ 不剪任何合法着法，连"填自己眼"都保留（AGZ 论文方法节 "Domain Knowledge"）。
2. **每局必然以确定终局结束**：双方 pass 或 722 手上限保证终止，终局结果 $z$ 由规则给出；于是每个访问状态都有标签（命题 1.1）。
3. **即使价值网络随机，MCTS 也能产生非退化的策略改进**：PUCT 的探索项给出访问下界与全支撑（命题 1.4）；改进算子在"估计世界"里恒有正改进（命题 1.8）。
4. **探索与稳定机制**：根 Dirichlet 噪声、温度退火、评估器门控、数据回放、对称增广、认输过滤。它们各自解决一个明确的数学问题（§1.4）。

其中条件 1、2 是**棋盘博弈的专属幸运**，条件 3、4 是算法侧的保障。第 04 章将证明：在证明搜索里条件 1、2 都不成立（动作是无限字符串集合、标签只在成功轨迹上），因此 AlphaProof 必须引入预训练支撑与 one-hot 目标等结构性替代。

### 1.3.2 标签永远可得：无偏性与密度

**命题 1.1（自博弈终局标签的无偏性与密度）**

*假设*：

- (I1) 对局是完全信息、二人零和、交替行动的有限博弈；状态编码"轮到谁走"（AGZ 输入含颜色平面）。
- (I2) 固定策略 $\alpha$（本轮由网络与搜索产生的落子策略，含根噪声与温度采样），对局双方都按 $\alpha$ 落子（自博弈）。
- (I3) 对局几乎必然在有限步内终止（围棋：双方 pass 或 722 手；AZ 三棋类：另有超长对局判和与认输规则）。
- (I4) $z_t$ 定义为"从时刻 $t$ 的行动者视角看的终局结果"，取值于 $\{-1, 0, +1\}$（AGZ 围棋为 $\{-1, +1\}$）。

*陈述*：对每局自博弈的每个访问时刻 $t$，

$$
\mathbb{E}\big[\, z_t \,\big|\, s_t,\ \text{时刻 } t \text{ 被到达} \,\big]
= V^{\alpha}(s_t)
:= \mathbb{E}\big[\, z_t \,\big|\, s_t \,\big], \tag{1.1}
$$

且 $\mathrm{Var}(z_t \mid s_t) = 1 - V^{\alpha}(s_t)^2 \le 1$（围棋二值情形）。此外，长度为 $T$ 的对局产生 $T + 1$ 个状态–标签对：**每访问一个状态就得到且仅得到一个标签，标签密度恒为 $1$**。

*证明*：在 (I2)–(I3) 下，从 $(t, s_t)$ 出发的后续对局是马尔可夫链：其转移概率只由规则与 $\alpha$ 决定，与 $t$ 之前的历史无关；$z_t$ 是该链终点的可测函数，故条件分布只依赖 $s_t$，其条件均值按定义为 $V^{\alpha}(s_t)$。形式地，

$$
\mathbb{E}[z_t \mid s_t]
= \mathbb{E}\Big[\ \mathbb{E}\big[z_t \mid s_t, \mathcal F_t\big] \ \Big|\ s_t \Big]
= \mathbb{E}\big[ V^{\alpha}(s_t) \mid s_t \big]
= V^{\alpha}(s_t), \tag{1.2}
$$

其中 $\mathcal F_t$ 为 $t$ 时刻的历史，第一个等号是条件期望的塔性质。方差：$z_t^2 \in \{0, 1\}$ 且当 $z_t \in \{-1, +1\}$ 时 $z_t^2 = 1$，故 $\mathrm{Var} = \mathbb{E}[z_t^2] - V^\alpha(s_t)^2 = 1 - V^\alpha(s_t)^2$。$\square$

**注 1.2（无偏 ≠ 独立；有效样本）** 同一局内的 $z_t$ 共享同一个终局，彼此强相关；"每局 $T+1$ 个标签"不等于"$T+1$ 个独立样本"。价值回归的有效样本量要按局内相关结构折减（有效样本的形式语言见 mstc-rl 05 §5.2 推论 5.5）。这正是回放窗口需要以"局"为单位（AGZ 取最近 500k 局）而不是以帧为单位的原因之一。

**注 1.3（标签对应改良策略）** (1.1) 的无偏目标是 $V^{\alpha}(s_t)$，而 $\alpha$ 是用上一轮网络跑搜索得到的**改良**策略（至少在其估计世界里优于网络策略，命题 1.8）。因此价值回归评估的是改良策略的值函数，回路是"改良 + 评估"的近似策略迭代（AGZ 论文方法节末段也把该算法解释为近似策略迭代；数据集 `math/10` §10.7）。

**与证明搜索的对照**：在证明搜索里，状态–标签对仅在成功轨迹上出现；一次尝试获得标签的概率是 $p_{\mathrm{solv}} \le 1$（mstc-rl 04 §4.5、05 §5.4 的删失模型），而且失败尝试上的"哪一步走错"完全不可观测。棋盘自博弈的标签密度 1 是条件 2 的直接算术后果，也是二者最本质的差别之一。

### 1.3.3 先验无用也不塌：PUCT 的探索地板

**命题 1.4（PUCT 的平衡、全支撑与无饥饿）**

*假设*：

- (E1) 当前搜索的根为 $s$，根动作数 $n = |\mathcal A(s)| \ge 2$，先验 $P(a) > 0$（AGZ 只掩非法动作，不掩任何合法着法）。
- (E2) 价值估计一致有界：$|\hat Q(s,a)| \le M$；选择规则为

$$
I_a := \hat Q(s,a) + C\,P(a)\,\frac{\sqrt{N_{\mathrm{tot}}}}{1 + N_a},
\qquad N_{\mathrm{tot}} = \sum_b N_b, \qquad C := c_{\mathrm{puct}}, \tag{1.3}
$$

  每次模拟选 $\arg\max_a I_a$。
- (E3) 每次模拟恰使一个根动作的访问计数加一（AGZ 的回传对路径上每条边恰加一）。

*陈述*：

(a) **零值精确平衡**：若 $\hat Q \equiv q$ 且先验均匀 $P \equiv 1/n$，则任意 $B$ 次模拟后 $|N_a - N_b| \le 1$，特别地 $N_a \in \{\lfloor B/n \rfloor, \lceil B/n \rceil\}$。

(b) **非退化先验下的全支撑**：若 $p_{\min} := \min_a P(a)$ 满足 $(n+1)p_{\min} > 1$，则每个动作在 $T_0 + n$ 次模拟内至少被访问一次，其中

$$
T_0 = \left\lceil \Big(\frac{4M}{C\,((n+1)p_{\min} - 1)}\Big)^2 \right\rceil; \tag{1.4}
$$

均匀先验时上式退化为 $T_0 = \lceil (4Mn/C)^2 \rceil$。

(c) **任意正先验下的无饥饿**：对任意 $P(a) > 0$ 与任意有界 $\hat Q$，当模拟次数 $B \to \infty$ 时每个动作被访问无穷多次；因此"所有动作都被访问过"在有限步内发生。

(d) **搜索策略的全支撑**：若所有动作已被访问且温度 $\tau > 0$，则访问分布 $\pi(a \mid s) = N_a^{1/\tau} / \sum_b N_b^{1/\tau}$ 对一切 $a$ 严格为正；$\tau = 1$ 时 $\pi(a \mid s) \ge 1/B$。

*证明*：

(a) 在假设下 $U_a = C P \sqrt{N_{\mathrm{tot}}}/(1+N_a)$ 是 $N_a$ 的严格减函数，故每步选计数最小者。对步数归纳：若当前 $\max_a N_a - \min_a N_a \le 1$，把 1 加到某个最小计数上，新的最大与最小之差仍 $\le 1$。初始全为 0，结论成立。$\square$

(b) 设 $a$ 未访问（$N_a = 0$），$b$ 已访问（$N_b \ge 1$）。则

$$
I_a - I_b
\ge -2M + C\sqrt{N_{\mathrm{tot}}}\,\Big( p_{\min} - \frac{P_b}{1+N_b} \Big)
\ge -2M + C\sqrt{N_{\mathrm{tot}}}\,\frac{(n+1)p_{\min} - 1}{2}, \tag{1.5}
$$

第二步用了 $P_b \le 1 - (n-1)p_{\min}$（其余动作先验至少 $p_{\min}$）与 $1 + N_b \ge 2$。因此只要 $\sqrt{N_{\mathrm{tot}}} \ge 4M/(C((n+1)p_{\min}-1))$，就有 $I_a > I_b$ 对一切已访问动作成立；未访问动作之间的并列按任意规则打破（例如优先未访问者）。于是全局 $\arg\max$ 落在未访问动作上，此后每步同理，至多 $n$ 步把所有动作访问一遍。$\square$

(c) 反证：设动作 $a$ 从某时刻起永远不被访问。对任意更晚时刻 $t$，被选动作 $b_t$ 满足 $I_{b_t}(t) \ge I_a(t)$，而 $I_a(t) \ge -M + C p_{\min}\sqrt{t}$。于是

$$
\frac{C\,P_{b_t}\sqrt{t}}{1 + N_{b_t}(t)} \ge C p_{\min}\sqrt{t} - 2M
\ \Longrightarrow\
N_{b_t}(t) \le \frac{P_{b_t}}{p_{\min}}\,\big(1 + o(1)\big). \tag{1.6}
$$

若某动作 $b$ 被访问无穷多次，(1.6) 沿这些时刻取极限得 $\sup_t N_b(t) \le P_b/p_{\min} + 1$；若只被访问有限多次，其计数有界。两种情形都给出

$$
N_{\mathrm{tot}}(t) = \sum_b N_b(t) \le \sum_b \Big(\frac{P_b}{p_{\min}} + 1\Big) = \frac{1}{p_{\min}} + n, \tag{1.7}
$$

与 $N_{\mathrm{tot}}(t) = t \to \infty$ 矛盾。$\square$

(d) 由 (b) 或 (c)，某个有限时刻后所有 $N_a \ge 1$；正性显然，$\tau = 1$ 时 $\pi(a) = N_a/B \ge 1/B$。$\square$

**注 1.5（结论的读法：探索地板 ≠ 学到东西）** 命题 1.4 只保证"根动作不会被结构性饿死"：即使网络输出近似随机的先验与值，搜索也不会因 $Q$ 的噪声永久放弃某个动作。它**不**保证在 1600 次模拟内访问全部 362 个动作：式 (1.4) 是最坏情形界，常数宽松；并且真实网络的先验远非均匀。冷启动真正的困难不在"动作是否被看见"，而在"看见后能否被正确地排序"（§1.3.5 的信噪比）。

**注 1.6（早期搜索目标近似均匀）** 由 (a)：若价值信号可忽略且先验近均匀，$B$ 次模拟把访问数摊成每动作约 $B/n$。AGZ 的 $B = 1600$ 与 $n \le 362$ 给 $B/n \approx 4.4$，即早期根访问分布接近均匀。这解释了自博弈第一轮为什么可以学习：策略目标 $\pi$ 是一个有宽支撑、非退化的分布（网络至少能学到"很多着法都不差"的平滑先验），而价值目标 $z$ 是一把有方向的信息（胜负），二者都不是零信号。

**引理 1.7（温度极限）** *假设* $N_b$ 有限、最大值集合 $A^* = \arg\max_b N_b$ 非空。*陈述*：当 $\tau \to 0^+$ 时 $\pi_\tau(a) \to 1/|A^*|$（$a \in A^*$）、$\to 0$（$a \notin A^*$）。*证明*：写 $\pi_\tau(a) = (N_a/N_{\max})^{1/\tau} / \sum_b (N_b/N_{\max})^{1/\tau}$；非最大项的比值严格小于 1，其 $1/\tau$ 次幂随 $\tau \to 0$ 趋于 0，分母趋于 $|A^*|$。$\square$ 这给 $\tau \to 0$ 的"贪心上限访问"提供了严格版本；当搜索值有噪声时并列最大几乎不发生，故落子近似取访问最多者。

### 1.3.4 改进算子的方向性：估计世界里的恒正与真实世界里的误差门槛

**命题 1.8（KL 正则改进：恒等式与带误差下界）**

*假设*：动作集有限；当前策略 $\pi$ 满支撑；真实动作值 $Q$；估计 $\hat Q$ 满足 $\|\hat Q - Q\|_\infty \le \epsilon$；温度 $\lambda > 0$；改进算子

$$
\hat\mu(a) = \frac{\pi(a)\,e^{\hat Q(a)/\lambda}}{\sum_b \pi(b)\,e^{\hat Q(b)/\lambda}}. \tag{1.8}
$$

（这是 (Z3) 的逐状态形式；$\lambda \to 0$ 时 $\hat\mu$ 趋于对 $\hat Q$ 的贪心。）

*陈述*：

(i) **恒等式**：

$$
\mathbb{E}_{\hat\mu}[\hat Q] - \mathbb{E}_{\pi}[\hat Q]
= \lambda\Big( \mathrm{KL}(\hat\mu\,\|\,\pi) + \mathrm{KL}(\pi\,\|\,\hat\mu) \Big) \ \ge\ 0, \tag{1.9}
$$

等号当且仅当 $\hat\mu = \pi$，即 $\hat Q$ 在 $\pi$ 的支撑上为常数。

(ii) **真实改进的条件下界**：

$$
\mathbb{E}_{\hat\mu}[Q] - \mathbb{E}_{\pi}[Q]
\ \ge\ \lambda\Big( \mathrm{KL}(\hat\mu\,\|\,\pi) + \mathrm{KL}(\pi\,\|\,\hat\mu) \Big) - 2\epsilon
\ \ge\ \frac{\lambda}{2}\|\hat\mu - \pi\|_1^2 - 2\epsilon. \tag{1.10}
$$

(iii) **贪心特例**：取 $\mu^* = \delta_{\arg\max_a \hat Q(a)}$，则

$$
\mathbb{E}_{\mu^*}[Q] - \mathbb{E}_{\pi}[Q]
\ \ge\ \max_a \hat Q(a) - \mathbb{E}_{\pi}[\hat Q] - 2\epsilon. \tag{1.11}
$$

*证明*：(i) 令 $Z = \sum_a \pi(a)e^{\hat Q(a)/\lambda}$。直接计算：

$$
\mathrm{KL}(\hat\mu\,\|\,\pi) = \frac{\mathbb{E}_{\hat\mu}[\hat Q]}{\lambda} - \log Z,
\qquad
\mathrm{KL}(\pi\,\|\,\hat\mu) = -\frac{\mathbb{E}_{\pi}[\hat Q]}{\lambda} + \log Z. \tag{1.12}
$$

两式相加再乘 $\lambda$ 即 (1.9)。两个 KL 非负，等号条件为标准结论（$\hat\mu = \pi$ 当且仅当 $\hat Q$ 在支撑上为常数）。

(ii) 由 $\|\hat Q - Q\|_\infty \le \epsilon$ 得 $|\mathbb{E}_{\hat\mu}[Q - \hat Q]| \le \epsilon$ 与 $|\mathbb{E}_{\pi}[Q - \hat Q]| \le \epsilon$，两式相减并套 (1.9) 得第一不等式；第二不等式用 Pinsker：$\mathrm{KL}(p\,\|\,q) \ge \frac{1}{2}\|p - q\|_1^2$。

(iii) 把 (i) 用于 $\hat\mu = \mu^*$，左端是 $\max_a \hat Q(a) - \mathbb{E}_\pi[\hat Q]$；再套 (ii)。$\square$

**注 1.9（"方向不依赖精度"这一常见表述的准确边界）** 常见说法是"价值误差只影响改进幅度，不影响改进存在性"。命题 1.8 说明这句话只有一侧成立：

- 在**估计世界**里 (1.9) 恒成立：只要 $\hat Q$ 在 $\pi$ 的支撑上非常数，$\hat\mu$ 就严格改进 $\mathbb{E}_{\pi}[\hat Q]$。这就是搜索在随机网络下仍然"有方向"的部分。
- 在**真实世界**里，(1.10) 要求估计出的改进量（KL 项或 (iii) 的槽口）大于 $2\epsilon$ 才保证严格改进；否则下界可能 $\le 0$。误差进入的不只是幅度，还决定"改进存在与否"的边界。这为第 04 章"模型误差经搜索放大"提供了精确的接口（对照 mstc-rl 05 §5.5 命题 5.17–5.18 的确定性/随机误差间隔条件）。

**命题 1.10（精确值下的策略改进定理；经典）**

*假设*：有限 MDP 或交替 Markov 博弈，折扣 $\gamma \in [0, 1)$，奖励有界；$\pi$ 为任意策略；$\pi'(s) \in \arg\max_a Q^\pi(s,a)$ 为对 $Q^\pi$ 的贪心策略。

*陈述*：$V^{\pi'}(s) \ge V^{\pi}(s)$ 对所有 $s$ 成立；等号成立当且仅当 $T_{\pi'}V^\pi = T_\pi V^\pi = V^\pi$（即 $\pi$ 在可达状态上已贪心）。

*证明*：记 $T_{\pi'}V(s) = r(s,\pi'(s)) + \gamma\sum_{s'}P(s' \mid s, \pi'(s))V(s')$。由贪心性逐点有 $T_{\pi'}V^\pi \ge T_\pi V^\pi = V^\pi$。$T_{\pi'}$ 单调且是 $\gamma$-压缩，故 $V^{\pi'} = \lim_{k\to\infty}T_{\pi'}^k V^\pi \ge V^\pi$（每个 $T_{\pi'}^k V^\pi \ge V^\pi$ 由归纳与单调性得到）。等号条件由压缩映射的不动点等式直接读出。$\square$

**注 1.11（博弈版本与搜索版本）** 在交替博弈中把 max/min 换成 AND/OR 的 $Q$ 变换（见 mstc-rl 01 定义 3.1 与专家迭代算子），单调性证明不变；把"一步贪心"换成"预算 $B$ 的 MCTS"，在叶值精确且树充分展开时改进只增不减（树内值不低于贪心值），但"叶值精确"这一前提在冷启动时恰恰不成立——这正是 1.3.5 的入口。深度搜索的价值不在于"一步贪心"，而在于它是**多步改进算子的采样近似**：AGZ 的 1600 次模拟把网络策略 $p$ 换成访问分布 $\pi$，使纯网络的 Elo 从 3055 提高到 5185（事实见 §1.1.1）。

**命题 1.12（近似策略迭代的误差邻域；经典结果）**

*假设*：同命题 1.10，但每轮策略评估只到精度 $\epsilon$：$\|\hat V_k - V^{\pi_k}\|_\infty \le \epsilon$，且策略改进相对 $\hat V_k$ 贪心。

*陈述（经典）*：在上述"值误差 $\epsilon$ + 贪心改进"的近似策略迭代下，策略值序列最终落在最优值的误差邻域内：$\limsup_k \|V^{\pi_k} - V^*\| = O\big(\epsilon/(1-\gamma)^2\big)$（Bertsekas & Tsitsiklis 的近似策略迭代分析；Bertsekas 2011 综述）。

*证明要点（缺口说明）*：① 用模拟引理比较贪心改进前后的值：一步改进把值误差按 $\gamma/(1-\gamma)$ 量级放大（奖励差先被 $P_{\pi'}$ 的几何级数累积）；② 再叠加评估误差 $\epsilon$，迭代得到几何级数 $\sum_k \gamma^k$ 的稳定点邻域 $O(\epsilon/(1-\gamma)^2)$；③ 有限视界（$\gamma = 1$、视界 $H$）的对应邻域是 $O(\epsilon H)$。本系列**不复制**该结果的精确常数：不同范数定义（加权 sup 范数 vs 无加权范数）下常数不同，引用只取"误差 ⇒ 邻域、不 ⇒ 发散"的结构性结论（详见 Bertsekas 2011；有限步博弈版本见 AGZ 论文方法节末段把算法解释为近似策略迭代的讨论）。

### 1.3.5 冷启动的真实困难是速度：信号存在性、信噪比与支撑缺席

**命题 1.13（自博弈回归信号：存在性、SNR 与"困难是速度"）**

*假设*：固定落子策略 $\pi$（本轮搜索产生的策略）；访问状态分布 $\nu$；终局标签满足命题 1.1：$\mathbb{E}[z \mid s] = V^\pi(s)$、$z \in \{-1, +1\}$（围棋）。

*陈述*：定义**信号** $S := \mathrm{Var}_{s \sim \nu}\big(V^\pi(s)\big)$ 与**不可约噪声** $N_0 := \mathbb{E}_{s \sim \nu}\big[\mathrm{Var}(z \mid s)\big] = \mathbb{E}_{s\sim\nu}[1 - V^\pi(s)^2]$。则：

(i) **偏置–方差分解**：对任意（不依赖 $z$ 的）预测子 $v$，

$$
\mathbb{E}_{(s,z)\sim(\nu,\cdot)}\big[(z - v(s))^2\big]
= \underbrace{\mathbb{E}\big[(z - V^\pi(s))^2\big]}_{N_0}
+ \underbrace{\mathbb{E}\big[(V^\pi(s) - v(s))^2\big]}_{\text{逼近误差}}; \tag{1.13}
$$

故 $V^\pi$ 是无约束最优预测子，超额风险恰为平方逼近误差。

(ii) **信号非退化判据**：$S = 0$ 当且仅当 $V^\pi$ 在 $\nu$ 的支撑上几乎处处为常数。若 $S > 0$，常数预测子 $v \equiv \mathbb{E}_\nu[V^\pi]$ 的超额风险恰为 $S$，即数据中存在真实可学的信号。

(iii) **冷启动刻画**：若模型类关于参数凸（如线性/广义线性模型）且 $V_{\theta_0}$ 不是该回归问题的最优解，则损失在 $\theta_0$ 处存在下降方向（凸损失的驻点即最优解，故非最优 ⇒ 梯度非零）。对深度网络，损失曲面非凸，(iii) 的这一步退化为经验陈述：随机初始化通常位于非驻点，且早期数据中确实存在可下降的方向 (S)。无论哪种情形，"能否学习"都不取决于标签是否存在（它总存在），而取决于信噪比 $S/N_0$ 与样本量：以经典回归界，把 $V^\pi$ 学到均匀误差 $\delta$ 需要样本量 $\Theta\big((d + \log(1/\eta))/\delta^2\big)$ 量级（$d$ 为模型类复杂度，(S) 只作量级声明），其中需要 $\delta \lesssim \sqrt{S}$ 才能分辨信号。

*证明*：(i) 展开：$(z - v)^2 = (z - V^\pi)^2 + (V^\pi - v)^2 + 2(z - V^\pi)(V^\pi - v)$；对 $s$ 取条件期望时交叉项因 $\mathbb{E}[z - V^\pi(s) \mid s] = 0$ 消失。(ii) 常数的超额风险是 $\mathrm{Var}_\nu(V^\pi)$；反之若 $S > 0$ 则非常数、常数预测子可被改进。(iii) 凸情形由"可微凸函数驻点即全局最小"得梯度非零；非凸情形是经验陈述，已标 (S)；样本量量级是经典回归结果。$\square$

**注 1.14（与证明搜索的分水岭：支撑缺席）** 命题 1.13 说明：棋盘冷启动不存在"可行性障碍"，只有"信噪比与样本量"障碍。证明搜索则同时有第二个障碍：**支撑障碍**。$\mathcal A(s)$ 是无限字符串集合，搜索只采样 $K$ 个候选（mstc-rl 01 命题 4.4）：最优战术若被采样概率为 0，就永远不在树中，增加预算也不能创造它（命题 4.25、例 4.27）。因此"先验无用也能改进"在棋盘上成立（探索地板 + 改进算子），在证明搜索上失效（先验决定支撑）。第 03、04 章分别对这两个障碍做定量刻画。

**注 1.15（迭代复合的改进链）** 把上述结论串成回路：第 $k$ 轮网络 $\theta_k$ →（搜索）→ 策略 $\pi_k = \alpha_{\theta_k}$，由命题 1.8 其在估计世界内优于网络策略、由命题 1.13 其值函数可学 →（自博弈）→ 数据 $(s, \pi_k, z)$，由命题 1.1 标签无偏 →（拟合）→ $\theta_{k+1}$，由命题 1.12 其评估误差 $\epsilon_{k+1}$ 决定下一轮改进的误差门槛 → 重复。回路要能持续改进，需要每轮的评估误差不随迭代累积放大；门控与回放窗口（§1.4）就是控制这一点的机制。形式化的专家迭代回路定义见 mstc-rl 01 定义 6.1。

## 1.4 工程保障各自解决的数学问题

### 1.4.1 评估器门控：分布漂移与假设检验

**事实**：AGZ 每 1000 步出一个检查点，与当前最优网络对局 400 局（每手 1600 sims、$\tau \to 0$），胜率 $> 55\%$ 才替换生成网络（AGZ 论文方法节 "Evaluator"）。AZ 则省略门控、用最新参数持续生成（AZ 论文正文）。

**计算（弃真与检验功效）**：围棋无和棋，记胜局数 $W \sim \mathrm{Bin}(400, p)$；"$>55\%$" 即 $W \ge 221$。用正态近似（连续性校正）：

$$
\Pr\big(W \ge 221 \mid p = \tfrac12\big)
\approx 1 - \Phi\big(2.05\big) \approx 0.020, \tag{1.14}
$$

$$
\Pr\big(W \ge 221 \mid p = 0.55\big) \approx 1 - \Phi(0.05) \approx 0.48,
\qquad
\Pr\big(W \ge 221 \mid p = 0.6\big) \approx 1 - \Phi(-1.95) \approx 0.97. \tag{1.15}
$$

即门控的假晋升率约 $2\%$，而一个真实优势仅 5% 的检查点只有约一半概率放行：这是一个相当严格的门槛（该数值化解读属本章推导，不是论文原话）。胜率 55% 对应的 Elo 差为

$$
\Delta e = 400\,\log_{10}\frac{0.55}{0.45} \approx 34.9. \tag{1.16}
$$

**解决的数学问题**：数据生成分布的非平稳漂移。若允许更弱的网络接管，自博弈数据的目标 $V^{\alpha}$ 会向更差的方向漂移，价值回归的靶子与策略改进的起点可能同时变差；门控把"分布每次移动的距离"用统计显著性兜住（对照数据集 `math/03` §3.5 与 `math/09` 的门控/Elo 分析）。

### 1.4.2 温度：探索的退火与目标分布的形状

**事实**：AGZ 前 30 手 $\tau = 1$（按访问计数比例采样），之后 $\tau \to 0$（贪心）；训练目标 $\pi_t$ 是搜索概率（AGZ 论文方法节 "Self-Play"、搜索节 "Play"）。

**数学对象**：(1.4) 的访问分布与引理 1.7 的温度极限。$\tau = 1$ 时目标保留探索信息（一个宽支撑的软分布），$\tau \to 0$ 时目标退化为对访问最多的动作的 one-hot。两段式的用途不同：开局需要拓宽状态分布覆盖（避免自博弈总走同一条线），中后盘需要用近乎最强的着法保证对局质量与标签质量。**一个需要标注的接口 (S)**：论文同一段用 $\pi_a \propto N^{1/\tau}$ 定义搜索概率、又规定落子温度前 30 手为 1、其后为 0，未明确区分"落子温度"与"写入训练目标的温度"；本地整理材料 `math/02` §2.2 把二者视为同一公式。第 04 章讨论 AlphaProof 的 one-hot 目标时，需要先对照这里的实现细节（见 §1.8）。

### 1.4.3 根 Dirichlet 噪声：先验的保险丝

**事实**：AGZ 用 $\eta \sim \mathrm{Dir}(0.03)$、$\varepsilon = 0.25$，混入根先验 $P(s_0,a) = (1-\varepsilon)p_a + \varepsilon\eta_a$；AZ 把 $\alpha_D$ 按棋类典型合法着法数缩放为 $\{0.3, 0.15, 0.03\}$（AGZ 论文方法节；AZ 论文方法节 "Configuration"）。

**计算（Dirichlet 矩）**：设 $n$ 个动作、对称参数 $\alpha_D$。由 Gamma 表示或 Beta 边缘分布，

$$
\mathbb{E}[\eta_a] = \frac{1}{n},
\qquad
\mathrm{Var}(\eta_a) = \frac{n-1}{n^2\,(n\alpha_D + 1)}. \tag{1.17}
$$

代 $n = 362$、$\alpha_D = 0.03$：$n\alpha_D + 1 = 11.86$，$\mathrm{Var} \approx 2.3 \times 10^{-4}$，标准差约 $0.015$；混合后的根先验期望为 $\mathbb{E}[P(s_0,a)] = 0.75\,p_a + 0.25/362 \approx 0.75\,p_a + 6.9 \times 10^{-4}$。**解决的数学问题**：如果网络先验把某个动作压到极小（或搜索的价值估计在该动作上恰好悲观），纯 U(s,a) 探索可能仍不足以在有限预算内访问它；根噪声给每个动作一个正的先验地板，使探索下界不依赖网络先验的尾部。注意它只作用于根、只在自博弈时开启——它是"数据分布的保险"，不是评估或最终落子的技巧。

### 1.4.4 回放：混合目标的偏差界

**事实**：AGZ 从最近 500,000 局均匀采样；AZ 持续训练、数据入回放；MiniZero 用最近 40,000 局（棋盘）或 1M 帧（Atari）的滑窗（AGZ 论文方法节 "Optimisation"；MiniZero 论文 §IV-A；数据集 `math/10` §10.3）。

**命题 1.16（旧数据的混合目标偏差）**

*假设*：训练分布是两代数据的混合 $\nu = (1-\beta)\nu_{\mathrm{new}} + \beta\nu_{\mathrm{old}}$；在状态 $s$ 上两代的条件标签均值为 $V_{\mathrm{new}}(s) = V^{\pi_{\mathrm{new}}}(s)$ 与 $V_{\mathrm{old}}(s) = V^{\pi_{\mathrm{old}}}(s)$；模型容量无限。

*陈述*：平方风险最优预测子为

$$
v^*(s) = \frac{(1-\beta)\nu_{\mathrm{new}}(s)V_{\mathrm{new}}(s) + \beta\nu_{\mathrm{old}}(s)V_{\mathrm{old}}(s)}{(1-\beta)\nu_{\mathrm{new}}(s) + \beta\nu_{\mathrm{old}}(s)}, \tag{1.18}
$$

于是

$$
\|v^* - V_{\mathrm{new}}\|_\infty
\ \le\
\Big(\sup_s \frac{\beta\nu_{\mathrm{old}}(s)}{(1-\beta)\nu_{\mathrm{new}}(s) + \beta\nu_{\mathrm{old}}(s)}\Big)\,
\|V_{\mathrm{old}} - V_{\mathrm{new}}\|_\infty. \tag{1.19}
$$

*证明*：总体风险按状态分解：

$$
\int \Big[ (1-\beta)\nu_{\mathrm{new}}(s)\,\mathbb{E}\big[(z - v(s))^2 \mid s, \mathrm{new}\big]
+ \beta\nu_{\mathrm{old}}(s)\,\mathbb{E}\big[(z - v(s))^2 \mid s, \mathrm{old}\big] \Big] \, ds. \tag{1.20}
$$

对每个 $s$ 的 $v(s)$ 求导，令导数为零得 $v^*(s)$ 为两代均值按概率权重 $\beta\nu_{\mathrm{old}}(s)$、$(1-\beta)\nu_{\mathrm{new}}(s)$ 的加权平均；偏差界由加权平均与 $V_{\mathrm{new}}$ 的差的绝对值不超过权重乘 sup 差得到。$\square$

**读法**：旧数据引入的偏差 =（该状态上旧数据的占比）$\times$（两代价值函数之差）。门控与短窗口分别压低这两个因子；而旧数据降低的是估计方差（偏差–方差权衡）。这给"回放窗口长度/门控频率"提供了一个可调的结构参数。

### 1.4.5 对称增广：群轨道与不变性

**事实**：围棋 8 重对称增广、MCTS 叶评估随机取对称变换；国际象棋/将棋不增广（AGZ 论文方法节；AZ 论文正文）。

**数学对象**：设 $G \cong D_4$ 为棋盘对称群、$|G| = 8$。围棋规则（除贴目与颜色）在 $g \in G$ 下不变，因此 $(\!g \cdot s,\, g \cdot \pi,\, z)$ 与原样本同分布；增广相当于把经验风险换成

$$
\hat L_G(\theta) = \frac{1}{8}\sum_{g \in G} \hat L(g \cdot \text{data}; \theta). \tag{1.21}
$$

两个后果：(i) 它把"网络输出不变"（值：$v(g \cdot s) = v(s)$；策略：$p(g \cdot s) = g_{\#}p(s)$）作为约束注入假设类，等价于用群平均后的特征做回归，若真实目标不变则**降低逼近误差**；(ii) 在理想化的线性模型与轨道内独立噪声假设下，轨道平均把估计方差缩小 $|G| = 8$ 倍——**但真实的自博弈 8 个副本共享同一个 $z$，不是独立样本**，因此实际收益小于 8 倍，主要来自不变性正则化与数据吞吐 (S)。MCTS 内的随机变换则等价于对叶子评估做 8 个对称偏置的集成平均。

### 1.4.6 认输：用 ≤5% 的标签噪声换算力

**事实**：根值与最佳子值低于 $v_{\mathrm{resign}}$ 即认输；阈值自动标定使假阳性率 $< 5\%$；10% 的对局禁用认输以测量该率（AGZ 论文方法节 "Self-Play"）。

**计算（标签噪声上界）**：认输把该局价值标签强制为 $z = -1$。若假阳性率为 $q$（认输局面中"其实可胜"的比例），则该处真实条件期望为 $2q - 1$（以概率 $q$ 得 +1、以概率 $1-q$ 得 −1），而标签恒为 $-1$，二者之差为

$$
\big|(-1) - (2q - 1)\big| = 2q \le 0.1. \tag{1.22}
$$

即用最多约 0.1 的局部偏差换取对已决局的算力节省；10% 的"禁用认输"子集给出了 $q$ 的无偏估计（随机抽样下）。这是"标签噪声预算"思想在 AGZ 里的早期工程实例（对照 mstc-rl 04 的删失与标签噪声讨论）。

## 1.5 MiniZero 的 progressive simulation：真实存在的"预算课程"

### 1.5.1 事实

- **设置**：MiniZero 在 9×9 围棋、8×8 Othello、57 个 Atari 游戏上对比 AlphaZero、MuZero、Gumbel AlphaZero、Gumbel MuZero（MiniZero 论文摘要）。
- **progressive simulation**：保持总模拟预算 $B$ 不变，在 $I$ 次迭代间动态分配 $n_i \in [N_{\min}, N_{\max}]$：先全体置为 $N_{\min}$，然后按 $N_{\max}, N_{\max}/2, N_{\max}/4, \dots$ 的目标从后往前逐步加大（每次最多用剩余预算的一半），最后把剩余预算补给模拟次数最少的迭代（MiniZero 论文 §III-C 与 Algorithm 1）。
- **典型配置**：$I = 300$、$B = 4800$、$(N_{\min}, N_{\max}) = (2, 200)$，与固定 $n = 16$ 的基线**总预算相同**（MiniZero 论文 §IV-F、Fig. 2）。
- **结果**：两块棋盘游戏上，progressive simulation 的训练末性能优于同预算固定模拟数基线；但在 54,000 步（270 次迭代）之前更弱，之后反超；8×8 Othello 在 $n$ 超过 16 后出现一次约 276 Elo 的跳升（MiniZero 论文 §IV-F、Fig. 10–11）。
- **Atari 上不通用**：$(N_{\min}, N_{\max}) = (2, 50)$ 对比固定 18：人类归一化平均回报 359.97% vs 395.87%，仅在 25/57 个游戏上占优；有的游戏模拟越多越好、有的越少越好（MiniZero 论文 §IV-F、Table III）。
- **适用对象**：progressive simulation 用于 **Gumbel Zero 训练**；MiniZero 自己训练的 AlphaZero 实例用的是固定 200 次模拟（MiniZero 论文 §IV-B）。因此它既不是 AGZ 的方法，也不能概括为"AlphaZero 用了课程"。

### 1.5.2 一个简化模型：为什么"先小后大"可能最优

**命题 1.17（精度–预算单调性；交换论证）**

*假设*：$K$ 次迭代，第 $k$ 次迭代的模型精度为 $q_k = 1/\epsilon_k > 0$（$q_k$ 随训练递增，例如值/策略误差递减）；在精度 $q$、模拟预算 $B$ 下，该迭代对最终性能的贡献为 $F(B) \cdot q$，其中 $F: [0,\infty) \to [0,\infty)$ 严格递增、$F(0) = 0$；总预算 $\sum_k B_k = C$ 固定。

*陈述*：任一使所有 $B_k > 0$ 的最优分配满足：$q_k \ge q_j \Rightarrow B_k \ge B_j$。特别地，若精度随迭代递增，则最优预算在训练过程中非降：**早期该少算、后期该多算**。

*证明*：反设存在 $q_k > q_j$ 但 $B_k < B_j$。考虑把两者的**预算水平互换**（$B_k \leftrightarrow B_j$，总预算不变）。两次贡献之差为

$$
F(B_k)q_k + F(B_j)q_j - \big[F(B_j)q_k + F(B_k)q_j\big]
= \big(F(B_k) - F(B_j)\big)(q_k - q_j) < 0, \tag{1.23}
$$

因为 $F$ 严格递增且 $B_k < B_j$，而 $q_k > q_j$。故互换严格改进，与原分配最优矛盾。$\square$

*数值例*：$F(B) = \sqrt B$、$q_1 = 1$、$q_2 = 4$、$C = 100$。最优满足 $1/(2\sqrt{B_1}) = 4/(2\sqrt{B_2})$，即 $B_2 = 16B_1$，得 $B_1 \approx 5.9$、$B_2 \approx 94.1$——把 94% 的算力放到更晚、更准的迭代。这正是 MiniZero 阶梯预算的定性形状；其 (2, 200) 阶梯是"每迭代最少 2 次、上限 200 次"的 bang-bang 近似。

**命题 1.18（搜索的双面性：为什么精度低时最优预算可能为 0）**

*假设*：模型 (S)：第 $k$ 次迭代的收益增量可写成

$$
\Delta V(B, \epsilon) = F(B) - c\,\epsilon\,G(B),
\qquad F(B) = 1 - e^{-\lambda B},\quad G(B) = B,\quad \lambda, c > 0, \tag{1.24}
$$

其中第一项是搜索带来的改进饱和曲线，第二项是价值误差经搜索深度放大的偏差（"规划可能使决策变差"的一般化，其经验背景见 MiniZero 论文 §IV-F 引用的规划–评估文献）。

*陈述*：
(i) 边际分析：预算 $B$ 处的边际收益 $\partial \Delta V/\partial B = \lambda e^{-\lambda B} - c\epsilon$。搜索在 $B$ 处"越算越亏"当且仅当 $\lambda e^{-\lambda B} < c\epsilon$。
(ii) 内部最优：当 $c\epsilon < \lambda$ 时 $B^*(\epsilon) = \frac{1}{\lambda}\log\frac{\lambda}{c\epsilon}$；$B^*$ 关于 $\epsilon$ 严格递减，且当 $c\epsilon \ge \lambda$ 时 $B^* = 0$（不做搜索最优）。

*证明*：对 $B$ 求导并令为零：$\lambda e^{-\lambda B} = c\epsilon$，解出 $B^*$；二阶导 $-\lambda^2 e^{-\lambda B} < 0$ 保证凹性，故为全局最大点；$B^*$ 对 $\epsilon$ 的导数为 $-1/(\lambda\epsilon) < 0$；$B^* > 0$ 当且仅当 $c\epsilon < \lambda$。$\square$

*读法*：命题 1.18 是 (S) 模型，不是 AlphaZero 算子的定理；它的价值是把 MiniZero 的实验结论（早期多算有害/无益、后期多算有利）与 Atari 上"并非通用"的现象组织成一句可检验的话：**当且仅当价值误差的放大项大于搜索的改善项时，应缩减预算**。这也是第 03 章"课程定理"的一个可用模板。

### 1.5.3 与 matchmaker 的类比

证明搜索侧的对应机制是 AlphaProof 的 matchmaker：预算按 $B(p) = \min(B_{\mathrm{cap}}, B_0 m^{f_p})$ 随同一道题的失败次数几何增长。它在 mstc-rl 05 §5.6 定理 5.21 中被严格化：在 Gamma–指数模型与固定后验风险下，$B_k = B_0 m^k$ 是精确解，$m = u^{-1/\alpha}$ 由风险水平与先验形状决定。

两者的**共同结构**：预算的边际价值随"当前对问题的把握"上升而上升，因此把算力推迟到更有把握的阶段（或更可能的难题上）是次优性可证的调度；两者的**不同轴**：MiniZero 沿训练迭代（模型精度 $q_k$ 递增）分配，matchmaker 沿同一道题的尝试次数（后验不确定性递减）分配。共同的可迁移教训：**预算课程是可以被形式化、被最优性判据检验的对象**，而不是只能凭直觉调的工程技巧；但两套模型都不能直接断言对方场景里的常数（05 §5.6 的"模型内严格化"注记同样适用于命题 1.17–1.18）。

## 1.7 本章结论

1. **课程之问（Q2 事实部分）**：AGZ/AZ 主结果直接在目标棋盘上从随机权重训练，没有小棋盘课程；"4×4 之问"的否定结论由输入/输出形状、终止规则、训练管线三处独立证据支持（§1.2）。常见误记来源是 MiniZero 的 9×9/8×8 实验设置、社区跨棋盘迁移、AlphaGo(2016) 的人类数据阶段与教学小棋盘。
2. **冷启动四条件**：合法动作有限且全部可用；每局必达确定终局；搜索在弱先验下仍非退化（探索地板 + 估计世界的改进）；探索与稳定机制齐备（§1.3.1）。其中前两条是棋盘博弈特有的，证明搜索不具备。
3. **命题 1.1（标签无偏与密度）**：自博弈的每个访问状态都得到终局标签，标签密度恒为 1、条件均值是无偏的值目标；这是"自我博弈能学习"的最基本事实，也是与成功-only 的证明搜索监督（密度 $p_{\mathrm{solv}} \le 1$）的分水岭。
4. **命题 1.4（探索地板）**：均匀先验 + 零值时访问精确平衡；非退化先验 $(n+1)p_{\min} > 1$ 时所有动作在有限可界时间内被访问；任意正先验下无饥饿。搜索策略因此对根动作保持（在有限时间后）全支撑。
5. **命题 1.8（改进算子的准确边界）**：估计世界内改进恒正；真实世界内只有"估计优势 > 2 倍误差"才保证严格改进。误差既影响幅度也决定存在性边界；这是"先验无用也能改进"这一口号的精确适用范围。
6. **命题 1.13（冷启动是速度问题）**：自博弈回归信号 $S > 0$ 只要当前策略的值函数非常数；学习可行性无碍，样本量按 $1/\delta^2$ 计，需要 $\delta \lesssim \sqrt{S}$ 才能看见信号。AGZ 的 490 万局、70 万 mini-batch、1600 sims/手就是把这个样本量补齐的代价。
7. **工程机制的数学对象**：门控（假设检验：假晋升约 2%、55% 对应约 34.9 Elo）、温度（访问分布与 $\tau \to 0$ 贪心极限）、根噪声（Dirichlet 矩与先验地板）、回放（混合目标偏差界 命题 1.16）、对称增广（群轨道不变性，$|G| = 8$）、认输（≤5% 假阳性 ⇒ 标签偏差 ≤ 0.1）。
8. **预算课程（Q2 机制部分）**：MiniZero 的 progressive simulation 是真实的预算课程（棋盘游戏有效、Atari 不通用）；命题 1.17 的交换论证给出"精度越高、最佳预算越大"的充分结构；命题 1.18 给出"误差主导时缩减预算"的判据；与 matchmaker 的 $B_0 m^{f_p}$（mstc-rl 05 定理 5.21）构成同构的两条轴。

## 1.8 (S) 与存疑

- **(S) 搜索超参与学习率细节**：AGZ 说 MCTS 搜索参数用 Gaussian process 贝叶斯优化选定（并用小 run 的网络为 40 块 run 重做一次），但本机材料未给出 $c_{\mathrm{puct}}$ 的具体数值与优化结果；AZ 声称"除噪声强度外全部超参相同"，同样未列搜索常数。引用具体 $c_{\mathrm{puct}}$ 需查论文扩展数据（本机不可得）。
- **(S) 训练目标的温度耦合**：AGZ 论文同一段用 $\pi_a \propto N^{1/\tau}$ 定义搜索概率，并规定前 30 手 $\tau = 1$、其后 $\tau \to 0$；"写入训练样本的 $\pi_t$ 用的是哪个温度"在论文文字中未明确区分。本地整理 `math/02` §2.2 采用同一公式。与 AlphaProof one-hot 目标的对照（第 04 章）需要先确认这一实现细节。
- **(S) 学习率表**：数据集 `math/02` §2.9 把 Extended Data Table 3 记为"图片不可提取"；本地论文 Markdown 的表格给出了具体阶梯（§1.1.1 已引用）。若两个来源冲突，以论文表格为准；本处标注为已核实的低风险项。
- **(S) 误记来源的清单**：社区跨棋盘迁移与教学小棋盘的具体项目、设置与规模未在本地材料逐条核对；§1.2.2 中这两条只作为"可能来源"陈述，不作事实断言。
- **(S) 命题 1.4 的常数**：式 (1.4) 是最坏情形界（对所有有界 $Q$ 一致），在 $M = 1$、$n = 362$、$C = 1$ 时给出 $T_0 \sim 2 \times 10^6$ 次模拟，远大于 AGZ 的 1600。因此**不能**由此断言"AGZ 每步都访问了全部合法着法"；实际覆盖率取决于真实先验分布与价值结构。命题 1.4 的用途是"无结构性饿死"的定性保证。
- **(S) 命题 1.13(iii) 的样本量量级**：$\Theta((d + \log(1/\eta))/\delta^2)$ 是经典回归界的量级声明，未指定具体模型类与范数下的常数；本章用它只有定性含义。
- **(S) 命题 1.16 的理想化**：把 $\nu_{\mathrm{old}}, \nu_{\mathrm{new}}$ 当作固定密度、两代条件均值按状态加权平均，忽略了价值函数随训练的非平稳漂移与网络容量限制；实际偏差还取决于旧数据占比随时间的调度。命题 1.16 的作用是给出可调参数（窗口长度、门控频率）的结构位置。
- **(S) 对称增广的收益因子**：轨道内副本共享同一 $z$，8 倍方差缩减只在"轨道内独立噪声"的玩具假设下成立；真实收益是"不变性正则化 + 吞吐提升"的混合，无纯方差因子可引用。
- **(S) 命题 1.17–1.18 的模型地位**：二者是组织 MiniZero 经验现象的简化模型（乘法可分的收益函数、线性偏差项），不是由 AlphaZero 算子推导出的定理；其参数 $c, \lambda$ 的标定方式未定。
- **事实性告诫（写作约束）**：不要把 MiniZero 的 progressive simulation 写成 AGZ/AZ 的做法，也不要把 9×9/8×8 实验平台写成"AlphaZero 的课程"；本系列后续章节引用时以本章 §1.2.3 的两类课程区分为准。
